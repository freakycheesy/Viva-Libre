# Cross-Platform* Mod Menu Project for Wobbly Life
Made for [MelonLoader](https://melonwiki.xyz/#/)/[LemonLoader](https://melonwiki.xyz/#/android/general) 0.6.5

# Quick Guide
Patch the game with MelonLoader/LemonLoader 0.6.5!
Download the latest [release](https://github.com/freakycheesy/Viva-Libre/releases) for your platform!
Copy the contents of the zipped folder into your Wobbly Life Directory!
and it should run!

# Controls

Action | Controller | Keyboard/Mouse | Touch
--- | --- | --- | --- |
Mod Menu | Left Stick Press | F2 | Mod Button |
Navigation | Left Stick/D-Pad | Arrow Keys | None |
Enter | A/Cross Button | Return Key | Tap |
Cancel | B/Circle Button | Backspace Key | Go Back |

- Gameplay Mods (modify the player or game state)
- Client Mods (modify your own client and save files)
